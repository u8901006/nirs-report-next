# nirs-report-modular：輸出報告介面視覺與互動規格

## 1. 文件目的

本文件補充 `nirs-report-modular-fNIRS-advanced-analysis-SPEC-v1.md` 的 UI/UX 與報告輸出章節，將程式的「結果／報告」頁改成與 `D:/心理學/NIRSdiff/NIR 介面.HEIC` 相近的報告式儀表板：

- 上半部依腦區排列所有通道的 HbO/HbR 波形縮圖。
- 下半部顯示 ROI 平均波形、Integral、Centroid、Slope 與 Integral–Centroid Plot Map。
- 以相同視覺系統延伸 LI、前後測差異與腦區活化差異結果。
- GUI 預覽與 Word 報告共用同一份結構化結果與圖表渲染規則。

本階段只定義規格，不修改程式、不變更 GitHub 儲存庫，也不建立執行檔。

## 2. 參考圖拆解

### 2.1 保留的視覺特徵

參考圖具有以下辨識度高且適合延續的特徵：

1. 白色報告畫布與細灰色區塊框線。
2. 頂部為腦區分組的多通道小型波形圖。
3. HbO/HbR 以紅、藍兩條線疊加顯示。
4. 底部左側為 ROI 平均波形與三個重點數值。
5. 底部右側以 Integral 為 X 軸、Centroid 為 Y 軸顯示區域位置。
6. 頁尾有「非臨床診斷」聲明。

### 2.2 必須調整的部分

- 參考圖使用 Right/Left Temporal Lobe；本程式目前的 15 通道配置是前額葉量測，因此不得沿用不正確的顳葉標籤。
- 改用 `Right Prefrontal Lobe`、`Anterior Frontal Lobe`、`Left Prefrontal Lobe` 及衍生的 `Lateral Frontal Lobe`。
- 參考圖的小圖過密、字體偏小；新介面需支援縮放、工具提示與選取放大。
- 不能只用顏色表示訊號與狀態；線型、標籤、圖示需同步表達。
- 缺失通道不得顯示成平坦的 0 波形，必須明確顯示缺失原因。
- 數值與圖表需標示單位、時間窗、有效通道數及分析設定。

## 3. 設計方案與決策

### 3.1 方案 A：完全仿照參考圖

把所有通道、兩張 ROI 波形與散點圖固定在單一畫面。優點是外觀最接近參考；缺點是加入 LI、前後測與腦區差異後資訊過密，且小螢幕難以閱讀。

### 3.2 方案 B：報告首頁相似、進階分析分頁（採用）

首頁維持參考圖的「上方通道矩陣＋下方 ROI 摘要與 Plot Map」，LI、前後測及腦區差異各有獨立結果頁。GUI 以頁籤切換，Word 以分頁輸出。此方案保留熟悉樣貌，也能完整呈現統計資訊。

### 3.3 方案 C：純卡片式儀表板

每個 ROI 與統計結果各自成卡，可自由重排，適合軟體操作但與預期報告外觀差異較大，且 Word 版面較難固定。

### 3.4 最終決策

採方案 B。報告首頁重現參考圖的資訊結構，不逐像素複製；進階統計使用相同字體、色彩、框線與圖表語言延伸。GUI 與匯出文件必須看起來屬於同一套產品。

## 4. 資訊架構

結果／報告區包含五個頁籤：

1. `總覽`：通道矩陣、Anterior Frontal、Lateral Frontal、Integral–Centroid Plot Map。
2. `側化 LI`：左右 PFC 波形、L/R/LI 數值、分類、CI 與 LI 圖表。
3. `前後測`：pre/post 波形、個人配對線、差值與 group × time 結果。
4. `腦區差異`：各 ROI 波形、heatmap、forest plot 及多重比較表。
5. `報告預覽`：頁面縮圖、顯示項目、品質警告、Word/Excel/圖片匯出。

沒有對應資料時，保留頁籤但顯示空狀態與建立方式，不顯示空白圖表或虛構數值。

## 5. GUI 整體版面

### 5.1 視窗結構

```text
┌──────────────────────────────────────────────────────────────────────────┐
│ NIRS 分析報告   [資料摘要] [品質：降級 2]            [重新分析] [匯出] │
├──────────────────────────────────────────────────────────────────────────┤
│ [總覽] [側化 LI] [前後測] [腦區差異] [報告預覽]                        │
├──────────────────────────────────────────────────────────────────────────┤
│ 報告畫布／分析內容                                           │設定抽屜│
│                                                             │圖例    │
│                                                             │時間窗  │
│                                                             │顯示項目│
├──────────────────────────────────────────────────────────────────────────┤
│ 100%  [－]────────[＋]  適合寬度  │ X/Y 通道有效 │ 非臨床診斷工具      │
└──────────────────────────────────────────────────────────────────────────┘
```

- 最小視窗尺寸：`1280 × 800 px`。
- 建議尺寸：`1600 × 1000 px` 或以上。
- 報告畫布置中，可垂直捲動；背景使用淡灰，畫布使用白色並有輕微陰影。
- 右側設定抽屜預設收合，展開寬度 300 px，不覆蓋圖表。
- 縮放範圍 60%–200%，提供「適合寬度」與「實際大小」。

### 5.2 狀態列

固定顯示：

- 有效通道數／預期通道數。
- 分析 chromophore 與指標。
- task/baseline window。
- 品質狀態 `完整`、`降級` 或 `無法分析`。
- 尚未儲存的設定變更提示。

### 6.2 區塊比例

- 報告畫布寬高比採 A4 landscape：`1.414:1`。
- 通道矩陣占首頁高度 43%。
- 下方摘要區占首頁高度 52%，頁首/頁尾占 5%。
- 下方左欄占 54% 寬，右欄占 46% 寬。
- 左欄兩張 ROI 卡等高排列。

### 6.3 通道矩陣

- 畫面由左至右依觀察者視角排列：Right PFC、Anterior Frontal、Left PFC。
- Right/Left PFC 各使用 `2 × 2` 小圖；Anterior Frontal 使用 `4 + 3` 小圖。
- 每張小圖固定顯示通道編號、HbO/HbR、0 基準線與 task window 淡色背景。
- 同一頁所有通道共用相同 X 軸；Y 軸預設共用同一範圍，允許切換「個別自動縮放」。
- 共用縮放為正式報告預設，個別縮放只能用於互動檢查，匯出時需標示。
- 小圖預設只在外圍顯示完整刻度，內部小圖省略重複文字以避免擁擠。
- 滑鼠停留顯示：通道、ROI、目前時間點 HbO/HbR、有效比例與警告。
- 點擊通道開啟放大視窗；Shift+點擊可多選比較。

### 6.4 通道狀態外觀

| 狀態 | 外觀 | 互動 |
|---|---|---|
| valid | 中性灰框，正常波形 | 可選取、放大 |
| selected | 2 px 深藍框，右上角勾選 | 可取消 |
| partial | 琥珀色框及 `!` 圖示 | 工具提示顯示有效比例 |
| missing | 灰底、斜線、文字「缺少 CHxx」 | 不畫 0 波形 |
| invalid | 淡紅底、錯誤圖示及原因 | 可查看錯誤詳情 |
| excluded_by_user | 降低透明度，顯示「已排除」 | 可重新納入 |

缺失或無效通道仍保留在 montage 的原位置，避免其他通道位移造成誤讀。

## 7. ROI 平均波形卡

### 7.1 卡片內容

首頁固定顯示：

- `Anterior Frontal Lobe Average Hb`：預設 ch5–ch11。
- `Lateral Frontal Lobe Average Hb`：預設 Right PFC 與 Left PFC 的有效通道合併平均。

每張卡包含：

1. 中英文 ROI 名稱。
2. HbO/HbR 平均波形。
3. baseline/task/recovery 區間底色。
4. Integral、Centroid、Slope 三個數值。
5. `有效 X/Y 通道` 品質標籤。
6. 單位、計算時間窗與警告圖示。

### 7.2 數值定義

- Integral 與 Centroid 沿用父規格所選的正值/帶正負積分與 centroid 規則。
- 首頁顯示的數值預設以 HbO 計算；使用者切換 HbR 時，標題與單位同步更新。
- `Slope` 定義為 recovery window `[task_end, measure_end]` 內，以時間為自變項、選定 ROI 訊號為依變項的普通最小平方法線性斜率。
- Slope 單位為訊號單位/秒；少於 3 個有效樣本、時間值不唯一或 ROI 無效時顯示 `無法計算`，不得顯示 0。
- 數值預設顯示 2 位小數；Slope 可顯示 4 位小數。完整精度保留在 CSV/Excel。

### 7.3 波形規則

- HbO：實線、`#D6455D`。
- HbR：實線、`#148FBD`，並以不同線寬/圖例區別。
- 0 基準線：灰色點線。
- task window：`#E8EEF5` 15%–25% 透明底色。
- 群組模式可顯示 95% CI 色帶；單一量測不顯示虛構 CI。
- 圖例順序固定為 HbO、HbR、Task window。

## 8. Integral–Centroid Plot Map

### 8.1 座標與標記

- X 軸：Integral，必須顯示單位。
- Y 軸：Centroid，單位秒。
- Anterior Frontal：藍色方形。
- Lateral Frontal：橘紅色圓形。
- 額外 ROI 使用不同形狀，最多直接顯示 8 個；超過 8 個時改用可捲動圖例。
- 每個標記旁顯示簡短 ROI 名；允許在設定抽屜關閉標籤。
- 點擊標記同步選取左側 ROI 卡與組成通道。

### 8.2 座標範圍

- 預設依資料自動縮放並保留 10% padding。
- 必須包含 X=0 與 Y=0；Centroid 不得小於 0。
- 使用者可鎖定 X/Y 範圍，鎖定值保存於分析設定並寫入報告。
- ROI 無有效 Integral 或 Centroid 時不畫標記，圖例旁顯示缺失原因。

### 8.3 聲明

圖表下方固定顯示：

> Integral–Centroid Plot Map 僅為血行動力反應摘要，不構成臨床診斷或療效判定。

## 9. 側化 LI 頁

### 9.1 版面

- 上方：Left PFC 與 Right PFC 平均 Hb 疊圖。
- 中左：L、R、LI 三張數值卡；LI 使用 `-1 ← 0 → +1` 水平刻度。
- 中右：LI 分布/CI 圖；單一個案顯示點估計，群組顯示個人點、平均與 95% CI。
- 下方：有效通道、分類切點、分母警告、統計方法與解讀限制。

### 9.2 視覺規則

- 左 ROI 使用紫色，右 ROI 使用綠色；HbO/HbR 線色仍維持紅/藍，避免把半球與 chromophore 混為同一色碼。
- LI 正值區淡紫、負值區淡綠、bilateral 區淡灰。
- 分母接近 0 或 L/R 異號時，LI 卡顯示琥珀警告，不顯示自動側化分類。

## 10. 前後測頁

### 10.1 單組

- 左側：pre/post ROI 平均波形，可切換疊圖或上下排列。
- 右上：個人 paired-line plot。
- 右下：平均差、95% CI、Cohen's dz/rank-biserial、p 值與完成配對 N。
- 排除資料以可展開表格列出，不混入有效 N。

### 10.2 兩組或多時間點

- 群組使用顏色，時間點使用點型/線型，避免只靠顏色。
- 主結果卡突出 `group × time`；組內 simple effects 降為次要資訊。
- LMM 未收斂時，結果區顯示診斷警告，不顯示「顯著/不顯著」徽章。

## 11. 腦區差異頁

- 上方：所選 ROI 平均波形 small multiples，使用相同 Y 軸。
- 左下：ROI × session/group heatmap，顯示共同色階與數值。
- 右下：forest plot，顯示各 contrast、95% CI、未校正與校正後 p/q 值。
- 表格列出 correction family 中的全部 comparisons，不只顯示顯著項目。
- `Lateral Frontal` 與其組成的 Left/Right PFC 不得同時作為互相獨立的 ROI 進入同一模型；介面需顯示原因。

## 12. 報告預覽與匯出流程

### 12.1 預覽頁

左側為頁面縮圖列，右側為大頁面預覽。預設頁序：

1. 封面與個案/研究資料。
2. 總覽頁。
3. 側化 LI（有執行才加入）。
4. 前後測（有配對分析才加入）。
5. 腦區差異（有執行才加入）。
6. 品質控管、缺失通道與排除清單。
7. 方法、參數、聲明與追溯資訊。

使用者可取消選擇非必要頁面，但「品質控管」、「方法與聲明」不可移除。

### 12.2 匯出格式

- Word：`.docx`，A4 landscape 為圖表頁，封面/長表格可使用 portrait 分節。
- 圖片：每頁 PNG，A4 landscape 300 dpi，即 `3508 × 2480 px`。
- PDF：本版只有在系統具備可靠離線轉檔器時啟用；否則按鈕隱藏，不產生不完整 PDF。
- 數據：`subject_level_results.xlsx`、`statistical_results.csv`、`analysis_config.json`。

### 12.3 Word 版面策略

採「混合式」輸出：

- 標題、個案資料、數值表、警告與方法使用 Word 原生文字/表格，保持可搜尋與可複製。
- 通道矩陣、ROI 波形與統計圖使用同一渲染器產生 300 dpi PNG，再插入 Word，以固定外觀。
- 不把整份報告扁平化成單張圖片。
- 圖片下方保留原生文字 caption、資料來源與警告。

## 13. 視覺設計系統

### 13.1 色彩

| 用途 | 色碼 |
|---|---|
| HbO | `#D6455D` |
| HbR | `#148FBD` |
| 主文字 | `#24313F` |
| 次要文字 | `#5E6B78` |
| 框線 | `#C9D1D9` |
| 畫布背景 | `#FFFFFF` |
| 應用程式背景 | `#EEF1F4` |
| 選取 | `#245B8A` |
| 警告 | `#C47A16` |
| 錯誤 | `#B33A3A` |
| 成功/完整 | `#2E7D5B` |

色彩需通過 WCAG AA 一般文字對比。紅/綠不得作為唯一的成功/錯誤辨識方式。

### 13.2 字體與尺寸

- Windows GUI：`Microsoft JhengHei UI`，fallback `Segoe UI`、sans-serif。
- Word：中文 `Microsoft JhengHei`，英文/數字 `Arial`。
- 報告頁主標題 18–20 pt；區塊標題 12–14 pt；正文 9–10.5 pt；通道小圖最低 7.5 pt。
- 數值採 tabular figures；同一列小數點對齊。

### 13.3 間距與框線

- 8 px spacing system：8、16、24、32 px。
- 區塊框線 1 px、圓角 2–4 px；報告頁避免過度卡片化。
- 互動選取框 2 px；鍵盤焦點框需清楚可見。

## 14. 互動與無障礙

- 頁籤、通道、ROI、圖例與匯出按鈕均可使用鍵盤操作。
- 圖表提供「查看資料表」；螢幕閱讀器可取得圖表標題、ROI、N、估計值與警告摘要。
- 色彩之外，HbO/HbR、組別、左右半球同時以線型、點型或文字區分。
- 介面縮放至 125%/150% Windows display scale 時不得裁切主要控制項。
- 所有圖表支援複製 PNG、另存 PNG 與複製數值表。
- 長時間批次渲染顯示進度、目前頁面與取消按鈕，取消後不留下半成品。

## 15. 資料與元件介面

報告畫面不得直接重新計算統計值。它只接收已驗證的結果模型：

```text
ReportViewModel
├─ metadata
├─ analysis_config
├─ channel_series[]
├─ roi_summaries[]
├─ laterality_result?
├─ prepost_result?
├─ regional_result?
├─ quality_summary
├─ exclusions[]
└─ provenance
```

每個圖表元件必須能：

1. 接收資料與視覺設定。
2. 在 GUI 顯示。
3. 以相同軸、色彩、圖例與標籤匯出 PNG。
4. 回傳可存入報告的 caption 與警告清單。

GUI renderer 與 report renderer 共用圖表資料轉換層，避免畫面數值與 Word 數值不一致。

## 16. 錯誤與空狀態

| 狀況 | 顯示方式 |
|---|---|
| 尚未分析 | 插圖/圖示＋「請先完成分析」＋返回設定按鈕 |
| ROI 無通道 | 保留卡片位置，顯示 `無有效通道` 與原因 |
| 部分通道缺失 | 顯示降級 banner、X/Y 與詳細清單入口 |
| Integral/Centroid 無法計算 | 數值顯示 `無法計算`，圖上不畫點 |
| 模型未收斂 | 統計卡顯示警告、診斷與調整建議，不顯示結論徽章 |
| 報告圖片生成失敗 | 指出失敗頁與圖表，可重試該頁；不覆蓋既有報告 |
| Word 儲存失敗 | 保留暫存輸出並提供另存路徑 |

## 17. 效能需求

- 15 通道單檔總覽首次顯示：一般 Windows 電腦目標 2 秒內。
- 頁籤切換：資料已計算時目標 300 ms 內。
- 圖表縮放/選取：目標維持可感知流暢，不在 UI thread 重算統計模型。
- 7 頁 Word＋300 dpi 圖表匯出：目標 15 秒內；超過 1 秒顯示進度。
- 圖表快取鍵包含資料 hash、分析設定 hash、尺寸與 dpi；資料或設定改變時自動失效。

## 18. 測試與驗收條件

### 18.1 視覺驗收

- 總覽頁肉眼可辨識為參考圖的同類布局：上方通道矩陣、左下兩張 ROI 波形卡、右下 Plot Map。
- 15 個通道均出現在固定 montage 位置，Right/Anterior/Left 分組正確。
- 1280×800、1600×1000、1920×1080 及 Windows 125%/150% scaling 無重疊或裁切。
- HbO/HbR、task window、ROI、警告及選取狀態在彩色與灰階列印中都可辨識。
- golden-image 測試使用固定字型與測試資料；排除抗鋸齒邊緣後，主要元件位置差異不得超過 3 px。

### 18.2 數值一致性

- GUI、PNG、Word 原生表格與 CSV 的 Integral、Centroid、Slope、LI 必須來自同一結果物件。
- 顯示值四捨五入不影響匯出原始精度。
- Plot Map 標記座標與 ROI 數值卡完全一致。
- 切換 individual/shared Y scale 只改變視圖，不改變數值。
- 缺失通道或無效 ROI 不得被渲染成 0 波形或 `(0,0)` 散點。

### 18.3 互動驗收

- 點擊通道能開啟放大圖；選取狀態同步到 ROI 卡與設定。
- 點擊 Plot Map 標記能定位相應 ROI 及組成通道。
- 鍵盤可完成頁籤切換、通道選取、縮放、預覽與匯出。
- 取消匯出後不留下目標 `.docx` 半成品。
- 未執行 LI/pre-post/regional 分析時，報告不加入對應頁。

### 18.4 Word 驗收

- Word 在 Microsoft Word 2019、2021、Microsoft 365 可開啟，無修復提示。
- A4 landscape 圖表不超出頁面，caption 與圖表不分頁。
- 300 dpi 圖在 100% 顯示下文字可讀，檔案大小有合理壓縮。
- 品質控管與方法聲明不可由一般報告勾選介面移除。
- 報告中的所有警告、X/Y 通道數、軸範圍與分類切點可追溯至 `analysis_config.json`。
